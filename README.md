# Yoga CachyOS Openbox

CachyOS Openbox configuration for Lenovo Yoga.

## Included

- Openbox
- Polybar
- Picom
- Alacritty

## Keybinds

- Super+Return — Alacritty
- Super+C — Close window
- Super+Q — Logout / power menu
- Super+1..4 — Switch desktop
- Super+Shift+1..4 — Move window to desktop
- Super+N — NetworkManager editor
- Super+Shift+N — nmtui
- Volume keys — volume up/down/mute

## Alacritty

- JetBrainsMono Nerd Font
- Font size: 7.0
- Opacity: 0.85

## Openbox

- Theme: cachyos-nord

## Polybar

- JetBrainsMono Nerd Font
- Font size: 10
- CachyOS + Openbox branding
- Workspaces
- Audio
- Memory
- CPU
- Wi-Fi
- Battery
- Clock

## Picom

- GLX backend
- Rounded corners
- Soft shadows
